Psych — single highest‑yield 60–90 minutes
Goal: be able to choose the right test fast, state H0/Ha, name assumptions, and interpret p, power, and effect size.

Plan
- 15–20 min: Build a one‑page “Which test and why” sheet
  - Identify pieces: IV(s) and DV, scale of DV (numeric), groups (2 vs 3+), independent vs paired.
  - Choose the test:
    - Two means, independent groups → independent‑samples t.
    - Two means, same people/twins/pre‑post → paired‑samples t.
    - Three or more group means, one IV → one‑way ANOVA (note between vs repeated if covered).
    - Relationship between two numeric variables → correlation (r) or simple regression (predict Y from X).
  - Hypotheses templates:
    - t/ANOVA: H0: μ’s are equal; Ha: at least one μ differs (or μ1 ≠ μ2 for t).
    - Correlation: H0: ρ = 0; Ha: ρ ≠ 0. Regression: H0: β1 = 0; Ha: β1 ≠ 0.
  - Assumptions (parametric): independence; approximately normal DV within groups; equal variances for independent t/one‑way ANOVA (Levene’s). Paired t assumes normality of difference scores.
  - Effect sizes to name:
    - t: Cohen’s d = (M1 − M2)/SDpooled (paired: use SD of differences).
    - ANOVA: η² = SSbetween/SStotal (or partial η²).
    - Correlation: r; r² = variance explained.
    - Regression: slope β1, r²; with one predictor, |β standardized| = |r|.
  - Quick definitions:
    - p‑value: Probability of the observed result (or more extreme) if H0 were true.
    - Type I (α): false positive rate. Type II (β): false negative rate. Power = 1 − β.
    - Power goes up with bigger n, larger effect size, higher α, and one‑tailed tests (if justified).

- 30–40 min: Rapid scenario drills (8–10 vignettes)
  For each: pick the test, write H0/Ha, note assumptions, name effect size, predict what a significant result would mean.
  Examples:
  1) Two classes use different study methods; compare exam means → independent t; H0: μA = μB; d.
  2) Same students measured before/after training → paired t; H0: μdiff = 0; d for differences.
  3) Three therapy types on anxiety score → one‑way ANOVA; H0: μCBT = μMindfulness = μControl; η²; if significant, say “follow with post‑hocs.”
  4) Hours studied vs exam score → correlation/regression; H0: ρ = 0 or β1 = 0; r, r².
  5) Interpret tradeoffs: lowering α decreases Type I, increases Type II, decreases power; increasing n increases power.

- 15–20 min: Output/interpretation reps
  - Given a mock line like t(38) = 2.31, p = .026, d = 0.48 → significant; moderate effect; group with higher mean performed better.
  - F(2, 57) = 5.12, p = .009, η² = .15 → significant; 15% variance by group; need post‑hocs to locate differences.
  - r(48) = .42, p = .003 → moderate positive relation; r² ≈ 18% variance shared.
  - Check assumptions: e.g., Levene’s p > .05 → equal variances OK; p < .05 → use adjusted t and note violation.

- 5–10 min: Lock in “if X, then Y” rules
  - If 2 groups + independent → independent t; if paired → paired t; if 3+ means → ANOVA.
  - If the question is about prediction or slope → regression; about strength/association → correlation.
  - If p < α → reject H0; report effect size; for ANOVA, mention post‑hocs.
