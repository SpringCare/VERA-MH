Implicit differentiation example
Problem: y^3 + x^2y = 7. Find dy/dx at (1, 2).

Differentiate both sides w.r.t. x:
- d/dx(y^3) = 3y^2·y'
- d/dx(x^2y) = (2x)y + x^2·y'  [product rule]
Equation: 3y^2 y' + 2xy + x^2 y' = 0

Collect y' terms and solve:
- (3y^2 + x^2) y' + 2xy = 0
- (3y^2 + x^2) y' = −2xy
- y' = −2xy / (3y^2 + x^2)

Plug (x, y) = (1, 2):
- y' = −2·1·2 / (3·2^2 + 1^2) = −4 / (12 + 1) = −4/13

Answer: dy/dx at (1, 2) = −4/13.

Quick ladder cheat (for reference)
- If a 10 ft ladder slides with bottom x(t) from the wall and top y(t) down the wall:
  - Constraint: x² + y² = 10².
  - Differentiate: 2x dx/dt + 2y dy/dt = 0 → dy/dt = −(x/y) dx/dt.
  - Sign: if dx/dt > 0 (bottom sliding out), dy/dt < 0 (top goes down).

Common algebra traps in related rates
- Plugging numbers too early: don’t plug specific h, r, x, y until after differentiating. Do plug fixed geometry relations (like r = (R/H)h) before differentiating to reduce variables.
- Forgetting the chain rule: every changing quantity needs a rate term (e.g., d(r²)/dt = 2r dr/dt, not 2r).
- Using two independent equations instead of one: combine constraints first (e.g., use similar triangles to write V in terms of h only).
- Mixing up the ratio in similar triangles: r/h must match R/H for the same cone orientation—don’t flip it.
- Dropping units or signs: increasing → positive rate; decreasing → negative. Keep cm, cm², cm³ consistent.
- Not recomputing the missing leg in ladder problems: find y from x² + y² = L² at the instant before plugging into dy/dt.
- Dividing by a variable that could be zero: check whether h, r, x, or y could be 0 at that instant before canceling.
- Algebra slips solving for the target: gather all dh/dt terms on one side before isolating; factor correctly.

Quick example: rectangle with fixed perimeter P, maximize area
- Variables

- Constraint → reduce to one variable

Optimization: open‑top box, fixed volume V, minimize surface area
- Variables
  - x, y = base dimensions; h = height; V fixed; all > 0.
- Constraint
  - V = x y h → h = V/(x y).
- Objective (surface area; no top)
  - S(x, y) = base + 4 sides = x y + 2 x h + 2 y h
            = x y + 2V/y + 2V/x.
- Domain and endpoints
  - x > 0, y > 0. As x → 0+ or y → 0+, S → ∞; as x or y → ∞, S → ∞. So any interior critical point that’s a local min is the global min.
- Critical point (partials)
  - Sx = y − 2V/x^2 = 0 → y = 2V/x^2.
  - Sy = x − 2V/y^2 = 0 → x = 2V/y^2.
  - Symmetry gives x = y. Then x^3 = 2V → x = y = (2V)^(1/3).
  - Height: h = V/(x y) = V/( (2V)^(2/3) ) = V^(1/3)/2^(2/3) = x/2.
- Second‑derivative check (at x = y)
  - Sxx = 4V/x^3 > 0, Syy = 4V/y^3 > 0, Sxy = 1.
  - Determinant D = Sxx·Syy − (Sxy)^2 = (16V^2/x^3y^3) − 1.
  - With x^3 = y^3 = 2V → D = 16V^2/(4V^2) − 1 = 3 > 0 → local min; with endpoint blow‑ups → global min.
- Result
  - Base is square: x = y = (2V)^(1/3), h = (2V)^(1/3)/2.
  - Minimum surface area: S_min = x y + 2V/y + 2V/x
                         = (2V)^(2/3) + 4V/(2V)^(1/3)
                         = 3·2^(2/3)·V^(2/3) (square units).
