- **Series and Convergence Tests** (Key for infinite series):
  - **Divergence Test**: If lim (a_n) ≠ 0 as n→∞, the series diverges. Quick check first.
  - **Geometric Series**: ∑ ar^{n} converges if |r| < 1, sum = a/(1-r).
  - **P-Series**: ∑ 1/n^p converges if p > 1.
  - **Ratio Test**: Compute lim |a_{n+1}/a_n| = L. Converges if L < 1, diverges if L > 1.
  - **Root Test**: lim ( |a_n|^{1/n} ) = L. Same rules as ratio.
  - **Integral Test**: If f(x) is positive, continuous, decreasing, then ∑ f(n) converges iff ∫ f(x) dx from 1 to ∞ converges.
  - **Alternating Series Test**: For alternating signs, if |a_n| decreases to 0, it converges (conditionally if not absolutely).
  - Cram Tip: Practice 1-2 examples each. E.g., For ∑ 1/(n ln n), use integral test: ∫ dx/(x ln x) = ln(ln x) → ∞, so diverges.

- **Integration by Parts** (Formula: ∫ u dv = uv - ∫ v du):
  - Choose u as what differentiates simply (LIATE order: Logs, Inverse trig, Algebraic, Trig, Expo).
  - dv = the rest (what integrates easily).
  - Examples to Run:
    - ∫ x e^x dx: u = x (du = dx), dv = e^x dx (v = e^x). Result: x e^x - ∫ e^x dx = x e^x - e^x + C.
    - ∫ ln x dx: u = ln x (du = dx/x), dv = dx (v = x). Result: x ln x - ∫ x (dx/x) = x ln x - x + C.
    - For reduction: ∫ sin^n x dx or similar—apply parts repeatedly.
  - Tip: Tabular method for polynomials times trig/expo (list derivatives of u down, integrals of dv across, alternate signs).
