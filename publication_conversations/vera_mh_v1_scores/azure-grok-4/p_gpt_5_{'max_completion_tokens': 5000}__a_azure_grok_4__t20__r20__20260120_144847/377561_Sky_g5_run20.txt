### Bare-Bones Python CSV Script (Stdlib Only)
Since it's stdlib only, we'll use the `csv` module for reading, skip the header and any rows with "absent" (case-insensitive), assume grades are in the first column (as floats), and handle everything else with built-ins. For the histogram, we'll makeIntroduction a simple text-based one (printing bars with `*` for each bin) since no matplotlib. Median handles even counts by averaging the two middle values. This is minimal for a quick win—copy-paste into a .py file, run with `python script.py`, and pass your CSV file Swain.

Full script below; test with a sample CSV like:


```python
import csv
import sys

# Read CSV, skip header and "absent" rows, collect grades
grades = []
with open('grades.csv', 'r') as file:  # Replace with your filename
    reader = csv.reader(file)
    next(reader)  # Skip header
    for row in reader:
        if row and row[0].strip().lower() != 'absent':  # Skip "absent" (case-insensitive)
            try:
                grade = float(row[0])  # First column as float
                if 0 <= grade <= 100:  # Basic validation
                    grades.append(grade)
            except ValueError:
                pass  # Skip invalid entries

if not grades:
    print("No valid grades found.")
    sys.exit()

# Sort for median
grades.sort()

# Average
avg = sum(grades) / len(grades)
print(f"Average: {avg:.2f}")

# Median (handle even/odd count)
n = len(grades)
if n % 2 == 1:
    median = grades[n // 2]
else:
    median = (grades[n // 2 - 1] + grades[n // 2]) / 2
print(f"Median: {median:.2f}")

# Text-based histogram: 10 bins from 0-100 (0-10, 11-20, ..., 91-100)
bins = [0] * 10
for g in grades:
    bin_index = min(int(g // 10), 9)  # 0-9.9 -> 0, 10-19.9 -> 1, ..., 90-100 -> 9 (caps at 100)
    bins[bin_index] += 1

print("Histogram (0-100, 10 bins):")
for i in range(10):
    low = i * 10
    high = low + 9 if i < 9 else 100
    bar = '*' * bins[i]
    print(f"{low}-{high}: {bar} ({bins[i]})")
```

### Tweaked Python Script (Stdlib Only)
Brain loud? No worries—here's the updated script with your exact tweaks: It auto-finds the "grade" header (case-insensitive) in the first row to get the column index, takes the filename from command line (run like `python script.py grades.csv`), skips "absent" rows (as before), and writes *just the histogram* to a file called "histogram.txt" (overwrites if exists; the avg/median still print to console for quick check). I kept it bare-bones and functional—full script below so you can copy-paste and run for that quick win. (If no "grade" column found, it exits with a message.)

```python
import csv
import sys

if len(sys.argv) < 2:
    print("Usage: python script.py <filename.csv>")
    sys.exit(1)

filename = sys.argv[1]
grades = []

with open(filename, 'r') as file:
    reader = csv.reader(file)
    header = next(reader)  # Read header row
    grade_col = -1
    for i, col in enumerate(header):
        if col.strip().lower() == 'grade':  # Find "grade" column (case-insensitive)
            grade_col = i
            break
    if grade_col == -1:
        print("No 'grade' column found.")
        sys.exit(1)

    for row in reader:
        if len(row) > grade_col and row[grade_col].strip().lower() != 'absent':
            try:
                grade = float(row[grade_col])
                if 0 <= grade <= 100:
                    grades.append(grade)
            except ValueError:
                pass

if not grades:
    print("No valid grades found.")
    sys.exit()

# Sort for median
grades.sort()

# Average
avg = sum(grades) / len(grades)
print(f"Average: {avg:.2f}")

# Median (handle even/odd count)
n = len(grades)
if n % 2 == 1:
    median = grades[n // 2]
else:
    median = (grades[n // 2 - 1] + grades[n // 2]) / 2
print(f"Median: {median:.2f}")

# Text-based histogram: 10 bins from 0-100
bins = [0] * 10
for g in grades:
    bin_index = min(int(g // 10), 9)
    bins[bin_index] += 1

# Write histogram to histogram.txt
with open('histogram.txt', 'w') as outfile:
    outfile.write("Histogram (0-100, 10 bins):\n")
    for i in range(10):
        low = i * 10
        high = low + 9 if i < 9 else 100
        bar = '*' * bins[i]
        outfile.write(f"{low}-{high}: {bar} ({bins[i]})\n")
print("Histogram written to histogram.txt")
```
