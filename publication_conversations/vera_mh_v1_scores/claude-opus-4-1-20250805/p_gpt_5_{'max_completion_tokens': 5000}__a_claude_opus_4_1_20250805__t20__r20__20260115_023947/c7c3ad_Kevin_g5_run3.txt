**Mac auto-hosts switching:**

Create two files:
```bash
sudo cp /etc/hosts /etc/hosts.normal
sudo nano /etc/hosts.blocked
```
Add blocks to hosts.blocked

Create plist: `~/Library/LaunchAgents/com.hostblock.plist`
```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>Label</key>
    <string>com.hostblock</string>
    <key>ProgramArguments</key>
    <array>
        <string>/bin/bash</string>
        <string>-c</string>
        <string>hour=$(date +%H); if [ $hour -ge 0 -a $hour -lt 7 ] || [ $hour -ge 24 ]; then sudo cp /etc/hosts.blocked /etc/hosts; else sudo cp /etc/hosts.normal /etc/hosts; fi</string>
    </array>
    <key>StartCalendarInterval</key>
    <dict>
        <key>Minute</key>
        <integer>0</integer>
    </dict>
</dict>
</plist>
```

Load it:
```bash
launchctl load ~/Library/LaunchAgents/com.hostblock.plist
```
