# Legacy scripts

These are the pre-2.0 entry points. They are deprecated and **may be removed at any time**. Use the [`vera` CLI](../docs/cli.md) instead; [docs/legacy-scripts.md](../docs/legacy-scripts.md) maps each script's flags to its `vera` equivalent.

Run them from the repository root as modules, for example `uv run python -m legacy.generate`, `-m legacy.judge`, `-m legacy.score`, or `-m legacy.run_pipeline`.
